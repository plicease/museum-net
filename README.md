# Museum Net

A controlled, portable network for vintage computers. Each gateway gives machines connected by Ethernet or serial useful local services, such as a read-only FTP/HTTP archive, without giving them unrestricted access to modern networks.

Development happens in an isolated virtual lab on Ubuntu; the same NixOS modules are later deployed to the physical gateways.
